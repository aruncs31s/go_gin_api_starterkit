# Go Gin Api Starter Kit

### Pre-requisites
- Go 1.20 or higher
- MySQL 8.0 or higher

### Installation
1. Clone the repository:
```bash
git clone https://github.com/aruncs31s/go_gin_api_starterkit.git
```
2. Navigate to the project directory:
```bash
cd go_gin_api_starterkit
```
3. Install dependencies:
```bash
go mod tidy
```

### Creating A New API Service (Project)
1. Create a folder for example `new_erp_backend`
2. Copy the contents of `go_gin_api_starterkit` into the new folder.
3. Update the `go.mod` file with the new module name:
```bash
module github.com/yourusername/new_erp_backend
```
